# GPPO worked example

This example exercises the production Workflow controller with the user's
12-signal A/B workbooks, two six-position gangs, experimental GPPO footprint,
800-pad interposer and separately authored RF-L2/RF-L3 artifact bundles.
The DXF files use mils; the saved board and configuration use millimetres.
Both gangs in DXF B are single columns on 0.325-inch pitch, numbered top to
bottom. J201 was a typo; both revisions use J101 and J102.

Run with a tested KiCad Python environment from the repository checkout:

```sh
/path/to/AppDir/AppRun python3.11 examples/gppo_demo/run_demo.py /tmp/new-gppo-demo
```

The destination must be new or empty. The script creates a source project from
the saved native DXF-B import, selects the read-only example parts, applies
netlist A into `applied-A`, verifies a repeated preview is `NOOP`, and applies
netlist B into `applied-B`. It records changes and recovery journal paths in
`demo-results.json`. Netlist B swaps the signals/classes while retaining the
physical connector positions and assigned routing layers. Initial layer rules
allow both classes on both inner layers.

Open the generated `.kicad_pro` in KiCad Manager, then PCB Editor and
**Tools → External Plugins → Connector to Interposer Workflow**. The saved sidecar
restores mappings, independent gang settings, selected artifacts and mechanical
inputs. Use **Review changes** before applying to a new output directory.
Source inputs and librarian parts are never overwritten by Apply.

`inputs/dxf-A-mils.dxf` and `inputs/dxf-B-mils.dxf` are independent import
fixtures. The script starts from B's
already imported native graphics so it does not substitute a private DXF parser
for KiCad's native import. Full A-to-B mechanical import interaction is a
separate manual acceptance scenario.

The library is experimental demonstration data, not librarian-approved
manufacturing data. The GPPO source was synthesized during Stage 0 from the
provided datasheet, and the interposer was generated by the separate existing
wizard. RF bundles are geometry examples, not tuned impedance solutions.
The board is deliberately unrouted and lacks completed ground planes.
Native DRC has exposed real annular-ring/default-rule and cutout-clearance
issues; do not fabricate it or lower constraints merely to erase those findings.
The review report distinguishes software reconciliation from RF, stackup and
fabrication qualification.
